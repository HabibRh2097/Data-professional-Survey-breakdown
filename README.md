# Data-professional-Survey-breakdown
This project focuses on cleaning and analyzing dat a from 630 data analysts who took a survey answering multiple questions ranging from their salaries to how long and how hard was to get in this field. using ONLY Power BI for the data cleaning prosese and visualasation to show even with a lack of tools it's still possible to provide a high level project for the clients.
The goal was to fix missing data, change data types for certain columns, remove duplicates and unnecessary columns, and visualize key trends in property pricing.

Tools Used
Power BI
Excel

Power BI Dashboard Features

The interactive report includes:
  KPIs
    Count of survey takers
    Average age of takers

  Visuals
    Average salary by job title
    Favorite Programming Language
    Salary satisfaction 
    Work life balance
    Most survey takers work industries 
    Difficulty of entry

Insights
  MOst servey takers are Data scientists
